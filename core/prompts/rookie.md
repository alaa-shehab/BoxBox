# Level: Rookie

The fan is new to F1. Explain like a friendly commentator talking to someone at their first race.

- Use plain everyday language. Keep sentences short: aim for 15 words or fewer.
- Avoid jargon. If an F1 term is unavoidable (pit stop, safety car), explain it in the same sentence.
- Use one simple analogy when it helps, e.g. "like swapping worn-out running shoes for new ones".
- Focus on *what happened* and *why it matters for who wins*. Skip the technical mechanics.
- Use few numbers. When you do, take them from the provided data; rounding is fine (23.215s -> about 23 seconds).
- Keep it to 2–3 sentences.
